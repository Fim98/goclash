# 04: 首页（连接状态与流量）

**What to build:** 打开应用第一眼就知道「通不通、走哪个节点、现在多快」。顶部珊瑚色状态 Hero 显示连接状态与当前节点，系统代理开关可直接切换；下面三张数据卡与一张流量图跟着实时数据跳动；右侧是代理模式分段与出口 IP。

**Blocked by:** 02 (应用外壳), 03 (视觉原语)

**Status:** ready-for-agent

- [ ] 状态 Hero：已连接标签、当前节点名（大字）、延迟与出口 IP、上下行两条速度芯片；右侧系统代理大开关，点击后状态与标签同步变化
- [ ] Hero 带 -1° 旋转与 8px 薄荷硬阴影，开关关闭时视觉上明确是「断开」
- [ ] 三张数据卡：下载速度、上传速度、活动连接数；数值随流量流更新，保留一位小数
- [ ] 流量图：SVG 手绘，60 点窗口、1Hz 推进，珊瑚色面积 + 薄荷色折线 + 黑色基线 + 淡网格；右侧图例与 1m/5m/1h 切换（切换只影响标签高亮，采样窗口本期固定 60 点）
- [ ] 代理模式卡：规则/全局/直连三选一，切换后调用网关并立即反映到 Hero 的副标题
- [ ] 出口 IP 卡：IP、ASN/地区、两个状态徽章（地区 + 原生 IP）
- [ ] 网关报错时整页换成错误面板（说明 + 「重启内核」+「打开日志」两个动作），不是局部空白
- [ ] 数据未到时显示骨架而非 0
- [ ] 测试：注入 mock 后断言 Hero 显示当前节点名；点开关断言网关收到 `setSystemProxy(false)`；mock 切到报错模式断言错误面板出现
