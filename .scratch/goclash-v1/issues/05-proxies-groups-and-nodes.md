# 05: 代理页（策略组与节点）

**What to build:** 用户在这里完成日常最高频的动作：挑一个策略组、点一个节点、看延迟对不对。策略组以卡片形式纵向排列，组内节点两列平铺，选中态一眼可辨；右侧固定一列，随时告诉用户「现在走哪、订阅还剩多少」。

**Blocked by:** 02 (应用外壳), 03 (视觉原语)

**Status:** ready-for-agent

- [ ] 策略组卡：组名、选择策略徽章（select/url-test/fallback/load-balance）、已选/总数、组内测速按钮
- [ ] 节点网格两列，每格显示节点名与延迟徽章；延迟按 <60ms 薄荷 / 60–150ms 阳光 / >150ms 蜜桃着色
- [ ] 选中节点：珊瑚填充 + 4px 边 + 4px 阳光影，文字与徽章反白；点击后调用网关 `select` 并立即更新
- [ ] 顶部工具条：代理模式分段、节点搜索框、全部测速按钮；搜索按名称过滤当前组节点
- [ ] 右侧栏从上到下：当前出口卡（珊瑚、-1°、显示节点与延迟）、代理提供者卡（两条提供者，可单独更新）、订阅流量卡（进度条 + 已用百分比 + 到期日）、链式代理卡（开关 + 代价说明）
- [ ] 没有订阅时显示空态：说明 + 「去订阅页」按钮（点击跳到订阅页）
- [ ] 测速过程中按钮进入禁用/加载态，结束后延迟刷新
- [ ] 测试：断言默认选中节点带选中态；点另一个节点断言网关收到 `select`；搜索输入后断言不匹配的节点消失
