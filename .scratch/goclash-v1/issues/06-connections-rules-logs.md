# 06: 连接、规则、日志三张表

**What to build:** 三个「看数据」的页面，共用同一套表格骨架，但各自解决不同问题：连接页回答「谁在偷跑流量」，规则页回答「为什么走了这条线」，日志页回答「刚才发生了什么」。三页都能筛选、都能停下来读。

**Blocked by:** 02 (应用外壳), 03 (视觉原语)

**Status:** ready-for-agent

- [ ] 连接页：黑表头（主机/命中规则/出口节点/上下行/时长/关闭），九行数据；被追踪的连接整行阳光高亮；逐行关闭与「全部关闭」；「自动刷新」开关可暂停列表
- [ ] 连接页筛选：全部/代理/直连/拦截四个芯片，带实时计数；页脚显示「显示 N / 总数」与已关闭数
- [ ] 规则页：类型/规则内容/匹配策略/命中次数四列；策略用彩色徽章（节点选择=薄荷、DIRECT=白、REJECT=珊瑚）；兜底 MATCH 行整行反白为墨黑底白字
- [ ] 规则页筛选：按类型筛选（DOMAIN/IP-CIDR/GEOIP/RULE-SET）、按命中排序与更新规则按钮
- [ ] 日志页：时间/等级/输出三列；等级标签配色 INFO=薄荷、DEBUG=白描边、WARN=阳光、ERROR=珊瑚反白；自动滚动开关；清空与打开日志目录两个动作
- [ ] 日志保留最近 512 条环形缓冲，超出后丢弃最旧一条并保持滚动位置正确
- [ ] 三页共用同一表格原语，表头与各行的列宽严格对齐
- [ ] 每页都有加载与空态（例如没有连接时提示「当前没有活动连接」）
- [ ] 测试：连接页点关闭断言网关收到 `closeConnection(id)`；规则页切到 REJECT 类断言只剩相关行；日志页切到 error 断言只剩错误行
