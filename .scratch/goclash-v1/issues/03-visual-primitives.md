# 03: 视觉原语组件集

**What to build:** 一套只负责长相与基础交互的组件，页面只组合它们、不自己写边框和阴影。所有组件共用同一套 hover / active / 焦点规则，开关与分段可键盘操作，表格能同时表达「普通行、选中行、反白行」。

**Blocked by:** 01 (工具链、视觉 token 与窗口尺寸)

**Status:** ready-for-agent

- [ ] 按钮三态：珊瑚填充 + 4px 边 + 6px 薄荷影 + -2°；hover 上浮并换成 8px 阳光影、转 3°；active 位移 6px、缩放 0.95、阴影归零；另有白底描边（ghost）与墨黑填充（ink）两个变体
- [ ] 图标按钮 44×44（可缩到 26/34），正方形、无圆角，长按不变形
- [ ] 卡片带四种硬阴影（珊瑚/薄荷/阳光/海沫），阴影不参与布局、不模糊
- [ ] 标签/徽章/芯片：2px 边、nowrap、`flex: none`，含五种强调色变体
- [ ] 分段控件：容器 4px 边、选中项填充，可键盘左右切换
- [ ] 开关：`role="switch"` + `aria-checked`，空格可切换；尺寸有 46×26 与 132×66 两档
- [ ] 输入框三态：默认 4px 边、聚焦加 4px 薄荷影且不改变尺寸、错误态边框与影换珊瑚
- [ ] 数据卡：标签 + 大数字 + 单位 + 右侧图标方块
- [ ] 表格：黑表头 46px、行 59px（紧凑版 53px）、行内支持选中/高亮/反白、页脚贴底；列宽用「固定 + 自适应」混排
- [ ] 状态面板：加载（描边骨架条，不用灰块）、错误（说明 + 主次动作）、空（图标 + 标题 + 主按钮）三态同构
- [ ] 每个原语至少 1 条测试：开关点击后 `aria-checked` 翻转、分段点击后选中项变化、表格渲染出给定行数
- [ ] `prefers-reduced-motion` 下所有位移与旋转消失，仅保留颜色变化
