# 07: 订阅与设置

**What to build:** 两个「改配置」的页面。订阅页管来源（哪几份订阅、用了多少、什么时候更新），设置页管开关（系统代理、TUN、开机自启这些）。所有改动即时写入网关，刷新后仍保持。

**Blocked by:** 02 (应用外壳), 03 (视觉原语)

**Status:** ready-for-agent

- [ ] 订阅页：两张订阅卡并排，内容包括名称、脱敏 URL、用量进度条与百分比、节点数/到期日/上次更新、立即更新/编辑/删除三个动作；当前使用的订阅带珊瑚「当前使用」标签
- [ ] 删除订阅需要二次确认，确认后卡片从列表移除
- [ ] 本地配置卡：名称（config.yaml）、「已合并」徽章、说明文案、编辑入口，以及 MERGE / SCRIPT / OVERRIDE 三块补丁摘要
- [ ] 自动更新卡：总开关、更新间隔分段（6h/12h/24h）、「更新后自动切到最低延迟节点」开关、「通过代理下载订阅」开关
- [ ] 设置页：2×2 四张卡——网络（系统代理/TUN/混合端口/允许局域网）、内核（代理模式/日志等级/内核版本/内核自动更新）、外观（主题/菜单栏延迟/语言/强调色）、系统（开机自启/静默启动/关闭行为/更新通道）
- [ ] 每个开关与分段改动立即调用网关并持久化到 mock 状态，切页再回来仍是新值
- [ ] 新建订阅按钮走一条最小路径：输入 URL → 卡片出现在列表（不校验真实可达性）
- [ ] 两页都有加载与空态（没有任何订阅时提示导入）
- [ ] 测试：切订阅页断言两张卡存在；点删除并确认断言卡片消失；在设置里关掉系统代理，回到首页断言 Hero 显示未连接
